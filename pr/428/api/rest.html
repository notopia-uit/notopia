REST API ​

Browse the endpoints by tag. Each endpoint page includes request and response details.

Document

  • Get document attachment upload url — GET /document/documents/{documentId}/attachment-url
  • Commit document — POST /document/documents/{documentId}/commit

Revision

  • Get revisions — GET /document/revisions
  • Get revision with content — GET /document/revisions/{revisionId}
  • Delete revision — DELETE /document/revisions/{revisionId}
  • Rename revision — POST /document/revisions/{revisionId}/rename

Workspace

  • Get workspace — GET /note/workspaces-by-slug/{workspaceSlug}
  • Check workspace slug exists — GET /note/workspaces-by-slug/{workspaceSlug}/exists
  • Create workspace — POST /note/workspaces
  • Get my workspaces — GET /note/workspaces/me
  • Delete workspace — DELETE /note/workspaces/{workspaceId}
  • Change workspace slug — POST /note/workspaces/{workspaceId}/change-slug
  • Empty trash — DELETE /note/workspaces/{workspaceId}/empty-trash
  • SSE workspace updates — GET /note/workspaces/{workspaceId}/events
  • Get workspace graph — GET /note/workspaces/{workspaceId}/graph
  • Leave workspace — POST /note/workspaces/{workspaceId}/leave
  • Get workspace members — GET /note/workspaces/{workspaceId}/members
  • Update workspace members — PUT /note/workspaces/{workspaceId}/members
  • Move workspace's items — POST /note/workspaces/{workspaceId}/move-items
  • Permanently delete workspace items — POST /note/workspaces/{workspaceId}/permanently-delete-items
  • Publish workspace — POST /note/workspaces/{workspaceId}/publish
  • Rename workspace — POST /note/workspaces/{workspaceId}/rename
  • Restore trashed workspace items — POST /note/workspaces/{workspaceId}/restore-trashed-items
  • Get Workspace Search Token — GET /note/workspaces/{workspaceId}/search-token
  • Show trash — GET /note/workspaces/{workspaceId}/show-trash
  • Trash workspace's items — POST /note/workspaces/{workspaceId}/trash-items
  • Get workspace tree — GET /note/workspaces/{workspaceId}/tree
  • Unpublish workspace — POST /note/workspaces/{workspaceId}/unpublish

  • Create folder — POST /note/folders
  • Permanently delete folder — DELETE /note/folders/{folderId}
  • Rename folder — POST /note/folders/{folderId}/rename

Note

  • Create note — POST /note/notes
  • Get note — GET /note/notes/{noteId}
  • Permanently delete note — DELETE /note/notes/{noteId}
  • Get note graph — GET /note/notes/{noteId}/graph
  • Get note links — GET /note/notes/{noteId}/links
  • Publish note — POST /note/notes/{noteId}/publish
  • Rename note — POST /note/notes/{noteId}/rename
  • Unpublish note — POST /note/notes/{noteId}/unpublish

NoteUser

  • Search users — GET /note/search-users

WorkspaceBilling

  • Get workspace entitlements — GET /billing/workspaces/{workspaceId}/entitlements
  • Get workspace billing — GET /billing/workspaces/{workspaceId}
  • Create checkout session — POST /billing/workspaces/{workspaceId}/checkout-session
  • Create portal session — POST /billing/workspaces/{workspaceId}/portal-session
  • Preview immediate cancellation — GET /billing/workspaces/{workspaceId}/subscription/cancel-now/preview
  • Cancel subscription now — POST /billing/workspaces/{workspaceId}/subscription/cancel-now
  • Claim payer role — POST /billing/workspaces/{workspaceId}/payer/claim
